# 项目索引

目录命名：`YYYY-MM-DD-NN-slug`。按日期排序，`NN` 是当天的序号，`slug` 用小写英文。每个项目目录的结构都一样：

```
README.md      项目卡：概况、成片、步骤、复盘
prompt.md      提示词（原样）+ 后续交互 + 拆解 + 复用版
media/         成片（Git LFS）
thumbs/        海报帧 + 逐帧预览（普通 Git）
scripts/       这个项目用到的脚本（可选）
transcripts/   旁白 / 字幕文稿（可选）
```
