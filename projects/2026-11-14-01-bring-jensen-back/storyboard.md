# Bring Jensen Back · 歌曲分析与分镜

> 下面的事实都是**量出来和转写出来的**，制作者听不到声音。量的方法见 lyric-mv 流程的 `listen.md`；脚本在 `scripts/`。

## 2. 歌词：实际唱的是什么

- **以用户的 txt 为准。** MP3 元数据里也嵌了一份歌词，但段落顺序不同（从 Verse 2 开头）。整首转写（faster-whisper large-v3-turbo，分离出的人声）证实实际演唱顺序和 txt 一致：Intro → Verse 1 → Pre → Hook → Verse 2 → Build → Drop → Verse 3 → Bridge → Final Hook → Outro。
- **和 txt 不一样的地方**（转写 + 频谱图）：
  - 开头 4.15–10.2 s 唱了两遍 "Bring Jensen back"，txt 里只有歌名那一行。
  - 第一遍副歌唱到 "先把证据摆上来" 就进了主歌二，txt 里的 "Facts first — then run it back — Bring Jensen Back!" 这一遍没唱。
  - Drop 后半是人声切片，见上表。
  - 结尾 256–262 s 是 "Then bring Jensen… back" 加回声，262–273 s 还有一段切片人声，转写不出词，不印字。
- **逐字时间：** 中文按字、英文按词，共 97 个演唱条目、1116 个单位。每个单位用 large-v3 和 large-v3-turbo × 人声和混音 × 三种窗口切法强制对齐，**每个单位 12 个独立估计取中位数**，大多数句子估计之间的四分位距只有 0.03–0.1 s。前奏的 "Bring him / Back" 呼应、开头歌名、"一九九三" 那一句（对齐把前一句的尾巴算了进来，早了 1.7 秒）、"resigned"、"Hold up"、第一遍副歌最后一句的头两个字对着人声频谱图手工改了起点（`scripts/timing.py` 的 `SEEN`）。

这首歌在对谁说话：对"我们"——热搜、散户、内网里留言的人。它说的事是正在发生的（辞职公告之后的一周）。转折句是 Bridge 的最后两句："If he's wrong — show the proof / If he's not — run it back"。全曲的立场是"先要证据，再谈回来"，不是洗白也不是审判。

## 3. 构思

**规则：字是被"印"上去的。** 这首歌一半在讲新闻标题，一半在喊口号，两样都是印出来的东西：报纸、牌子、印章、LED 屏。所以每个字在**被唱出来的那一帧**像橡皮章一样盖到画面上（0.1 秒的过冲，没有淡入），一句一直留到下一句开唱。字在各段的"命运"不一样：

| 段落 | 字是什么 | 怎么走 |
|---|---|---|
| 前奏 | 霓虹招牌的灯管（歌名）、打字机字 | 唱到哪个词哪个词亮 |
| Verse 1（传奇） | 舞台上的白/绿大字，身后 LED 墙每句只显示一个数字或一样东西：纸船、FUTURE、$40K、30 DAYS、1999、2006、AI、芯片、皮衣、MORE、FLASH、60:1、33、TOP | 下一句来就切 |
| Pre-chorus | 同上 | **摔下来**：唱到"摔"字主角掉出画面，第 29 小节鼓一停，整句字受重力掉落 |
| 副歌 | BRING JENSEN / BACK! 撑满上半屏，(Back!) 是另一种颜色斜着盖的回应章，中文答句贴在一条纸胶带上 | 盖章 |
| Verse 2（标题） | 报纸衬线体标题，红色日期章 10.29 / 11.08 / 11.09 / 11.12、EFFECTIVE IMMEDIATELY 章、红色 K 线、-11% | 下一条新闻盖过来 |
| Build | 计数器 0→1600、0→30,000+，签名滚动，绿色灯牌前的花和蜡烛 | READY? 3 2 1 |
| Drop | 一个词一整屏 | 跟着切片 |
| Verse 3（证据） | 等宽打字机字；"话也没有说全"被黑条涂掉，"照抄三年前的旧稿"盖 COPY / 2023 章，"阴谋论也不算证据"打红叉，最后盖 PENDING 章、光标停住 | — |
| Bridge（信） | 手写体，按字慢慢写出来；每封信配一样东西：咖啡杯（家人）、空椅子和一圈 60 个小人（同事）、门（董事会）、手机热榜被划掉（我们） | — |
| "run it back" | — | 字按演唱的**倒序**消失，画面倒带 |
| 尾奏 | 打字机字；最后霓虹招牌逐词重新亮起 | BACK 的回声一个比一个淡 |

**反复出现的东西：**
- **绿灯**：前奏"green light on"时窗外亮起；副歌"绿灯亮着 没人关"在主角身后变成一盏大灯；尾奏还亮着。
- **皮衣**：挂在后台的衣架上（副歌）、走下舞台（主歌二最后一句）、在旗杆上降半杆（主歌三的梗）、最后挂在卡座旁边的墙上。全片**不出现任何真人的脸**，那个人只以这件衣服和一把空椅子出现。
- **卡座和咖啡**：开头三只冒着热气的杯子（三个工程师）；结尾只剩一只，**不再冒气**（咖啡凉了），桌上多了花和蜡烛。

**主角（附图女孩）**：她是领喊的 MC。只有一张抠好的照片，所以"动"交给鼓点：头部在每个实测的底鼓、军鼓上点一下（脖子以上做小角度形变），身体在底鼓上轻微下沉，整帧在底鼓上冲击缩放。每段换一种印法：彩色贴纸（白边加绿色投影）、绿色网点、报纸油墨网点、复印机黑白、霓虹线描、宝丽来照片、波普网格。第一次出场在 "I say 'Bring him'" 那一拍；最后一次是尾奏里站在卡座旁边。
