## 3. 构思

**这首歌在对谁说话：** 一个老玩家对刚来的新人（「你」）。**说的事：** 正在发生，开局前三十秒；尾奏转成过去（当年有人这样给他讲过）和将来（下一个三十秒轮到你讲）。**转折：** 尾奏行 2，讲的人原来也曾是听的人，那个人已经下线了。

**叙事：** 三十秒的开局倒计时里，讲述者把整个世界讲给新人听；新人在静默里得到「召唤师」这个名字；副歌五个人出发；第二遍副歌在夜战里；终段日出，新人站到最前面。对面的水晶分三步结束：两次唱到推倒对面水晶的那一句时它裂开（K51），Drop 2 最后一小节碎开（K71），尾奏第一拍炸成光（K77，落在全曲最响的那一刻）；新人回头；讲述者想起当年给他讲的人；新人披上讲述者的灰斗篷，给下一个人翻转沙漏。最后一个画面回到第一个画面：石台上的沙漏，沙在流。

**反复出现的东西：** 黄铜沙漏（三十秒：前奏被翻转、倒数时只剩几粒、结尾又在流）；青色水晶（副歌里那座在身后发光的水晶：命名、三次副歌、倒数时裂而不碎）；营火和余烬（前奏的锅、尾奏烧尽的炭、新人点的新火）；讲述者的灰斗篷（尾奏换到新人身上）。

**人物的脸：** 新人的正脸只在尾奏「你回头」那一拍给一次（K78）。之前全是背影、手、逆光剪影；跳起来那一镜原本露了脸，重做成剪影。讲述者全程戴兜帽，不给脸。

**原创：** 歌词写的是一款真实游戏的世界。画面全部是原创的幻想世界：没有任何游戏角色、徽记、地图美术或奖杯原型，提示词里不出现任何作品名或角色名；地区和人物只取歌词里的意思（白墙、黑铁、风、王与雾、沙中帝国、星辰、小个子大魔法、虚空、双城、姐妹）。

## 4. 歌词规则：字是刻进这片土地的符文

主歌第一句就说了这片大陆刻满符文。所以这里的字不是字幕，是符文；符文怎么存在，取决于谁在刻：

| 状态 | 用在 | 字是什么 |
|---|---|---|
| carve 刻 | 讲述者的说唱（Intro 行 2–4、三段主歌、Pre-Chorus 1 行 1–2、Pre-Chorus 2 行 1、尾奏行 4） | 一点白热的光按演唱从左到右把字刻进场景表面（衬线黑体，按景深图贴着地形折过去），刀尖迸火星；刻槽里是熔金，槽沿烧黑；一句唱完冷却成橙红、暗下去 |
| light 光 | 唱的句子（三次副歌、Build-Up 行 1、Pre-Chorus 2 行 2–3、Intro 行 1、尾奏行 5） | 水晶的青光立在空中，透过它看到的场景被折射，边缘亮，一道高光扫过，随底鼓呼吸；句子结束时碎成碎片飞散 |
| stamp 印 | Drop 1 呐喊、倒数、Drop 2 | 一个词在它那一拍整个砸下来，放大回落，一圈冲击环，画面提亮一下 |
| neon 霓虹 | Bridge | 字只剩轮廓，是一根根玻璃灯管，逐字闪两下才亮稳；上城那一句是黄铜色，下城和姐妹的几句是粉色 |
| name 名 | Pre-Chorus 1 行 3 | 竖排成一列，像碑文一样立在水晶左边，在冻结的静默里白热刻出；副歌第一拍碎成青色的碎片 |
| ember 余烬 / memory 回忆 | 尾奏行 1、3 / 行 2 | 刻，但火很小、冷得快；回忆那句是褪色的褐色刻痕；行 3 最后三个字一直不冷（火未灭）；最后一遍清唱刻上去就不再冷却，一直亮到黑场 |

亮画面上（白墙、金色神殿、日出、爆炸）字周围的场景会按字下面的亮度局部压暗，只压亮的像素、跟着刻刀走：光在亮处是看不见的，所以符文点着的地方，世界暗下去一点。青光字和印字在亮处也会自动收一点光，免得冲成白块。

时间上的三条约束（渲染前用程序核对 736 个字全部满足）：每个字在唱出后 0.1 秒内出现在画面上；已经唱完的句子不跨到下一个镜头；一句的第一个字如果比切点早不到 0.26 秒，就等切点再出现，不在旧镜头上露头。

版式：一次一句，每行 2–5 个字、在句子自己的停顿处断行（不拆开专名和词），最宽一行撑满安全区宽度的 82%；四行及以上的句子分页，每页最多三行，唱到下一页的第一个字时翻页，每页放在它自己所在的镜头里；列地名的那一句一词一页，跟着八分音符的切点。安全区：x 50–940、y 220–1500。
