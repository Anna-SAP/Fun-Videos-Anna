## 关键制作步骤

1. **先确认三个素材是不是同一段音乐**（[playbook](../../playbooks/audio-sync-cross-correlation.md)）
   - 用 [`find_offset.py`](../../tools/av/find_offset.py) 把舞台版对 MV 做滑窗互相关：舞台版就是 MV 的 0:00–0:22，`舞台版时间 = MV 时间 + 1.0626 s`，没有漂移。卡通版沿用上次的 `+0.0407 s`。
   - 闭环校验：舞台版对卡通版单独测一次是 1.0219 s，正好等于 1.0626 − 0.0407。
   - 所以三路可以共用一个主时钟 T（= MV 时间）。成片时间 = T + 1.0626 s，舞台版比 MV 多出来的开头正好用作冷开场。
2. **求拍点网格**：频谱通量求起音，最小二乘拟合出 129.98 BPM。第 0 小节从 T = 0.196 s（歌曲第一拍）开始，每 1.8465 s 一小节；drop 是第 4 小节（T = 7.58 s），间奏是第 12 小节（T = 22.35 s）。每小节第 2 拍的鼓点最重（T = 9.89、11.74、13.58 s）。脚本里所有切点都写成 `D(小节, 拍)`。
3. **三路对齐后对照看内容**：每 0.5 秒拼一组三联帧，发现三版的段落完全平行：独舞开场 → 双人 → 全员队形，16 秒处 MV 和卡通版都有 A2O 标志和「Stage 1」字样。整条片子的结构就照着这个来设计。
4. **主体跟随裁切**（[竖屏构图 playbook](../../playbooks/vertical-9x16-composition.md)）：全屏时取景窗口只有原画面宽度的 31.6%，双人镜头两人离得太远，居中裁切会只拍到中间的白墙。用暗像素（头发）分布分出左右两人，固定跟拍右边的棕发成员。舞台版背景复杂，取景按画面手动定。
5. **逐帧合成**：脚本 [`scripts/render_neon_three_universes.py`](scripts/render_neon_three_universes.py)。三路源都用 ffmpeg 解码到同一条 30 fps 时间轴上（`tpad` 补开头 + `fps=30`；MV 直接用 4K 解码，全屏时画质更好），用 Pillow 和 numpy 合成：
   - 版式：三分屏（每条 1080×540，顶部留 210 px 放标题）和全屏之间做矩形 + 取景参数的缓动插值。
   - 霓虹元素：标题用 Bahnschrift Bold，叠加多层高斯模糊做发光；每个版本有自己的颜色（卡通粉、MV 青、舞台紫），用在边框、角标和扫过的光线上。
   - 背景：舞台版画面模糊压暗，只在分屏的缝隙和标题区露出来。
6. **音轨**：0–1.28 秒用舞台版的现场环境声，1.08 秒起淡出；之后接 MV 原声（延后 1.0626 s，48 kHz 下 51 005 个采样点），最后 0.9 秒淡出。卡通版和舞台版的音轨码率都低（74 / 50 kbps），只用 MV 的。
   - MV 母带很响：这一段 −10.6 LUFS，解码后的采样峰值已经到 +2 dBFS。整体降 3.5 dB，再过一个 −1.4 dB 的限幅器，成片 −14.1 LUFS（短视频平台常用的响度）。
   - AAC 192 kbps 在 T = 9.9 s 的重拍军鼓上编码后反弹到 +0.2 dBTP，改用 256 kbps 后真峰值 −0.6 dBTP。
7. **验证**：成片音频分别和舞台版、卡通版原音轨做互相关，偏差都是 5 ms，不到 1 帧。
8. **预览 → 修正 → 成片**：先用 `--scale 0.5 --fast` 出 540×960 预览（约 80 秒），按逐帧预览修了取景，再出 1080×1920 成片。

## 复盘

**做得好**
- **先用音频确认三版是同一段音乐，再动手设计。** 一旦有了共同的主时钟，“三个版本轮流出现”就不需要逐段对齐，任何时刻切到任何一版都是同步的。
- **结构跟着歌走。** 前奏比较空，用三分屏让观众认识三个版本；drop 之后用全屏卡拍轮换；间奏定格做结尾。切点都落在小节的重拍上，不是凭感觉切。
- **利用素材之间的巧合。** MV 画面出现「Stage 1」字样时，切进真正的舞台版；卡通版和 MV 构图一样的地方，用扫描线做“变身”。
- **跟拍同一个人。** 双人镜头只能容下一个人时，三个版本都跟同一位成员，切换时视线不用跳。

**踩坑 / 注意**
- 第一版预览里，MV 的双人中景（约 14 秒、20 秒处）居中裁切只拍到了中间的白墙；drop 前那几帧取景还停在上一个镜头的位置，画面是空的。要逐帧检查每个全屏段，不能只看几张关键帧。
- 第一版成片的音频真峰值 +2.2 dBTP：直接用了 MV 原声的电平，而 MV 本身就是满的。混音之后要先量一下 `ebur128=peak=true`，再决定增益和限幅。限幅后的 PCM 是干净的，但编码器还会让峰值反弹，所以要量**编码后的文件**。
- 分屏版式的边框是用 numpy 切片画的。面板滑出画面左边时 x 是负数，`slice(0, -72)` 变成了几乎整行，整条带子被涂成粉色。切片的起点和终点都要夹在 `[0, 宽度]` 之内。
- 舞台版有一段旋律和歌曲后面的段落一样，互相关在那里出了一个比正确位置得分还高的假峰（NCC 0.96）。要看多数窗口的结论。
- 「舞台版」的确切出处（哪个节目、是不是现场收音）没有核实，所以片中只写「舞台版」，没写“首秀”“现场”。
