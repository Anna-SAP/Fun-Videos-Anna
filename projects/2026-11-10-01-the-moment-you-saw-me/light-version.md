# The Moment You Saw Me · 光影版设计

歌词版（起雾的玻璃）之后的第二个歌词 variant，是五个备选方案里的 C「光写的字」。镜头、剪辑点和原曲音轨与成片完全相同，没有新生成图片。

歌词文字和歌词版一样只从 `TheMomentYouSawMe_lyrics.txt` 里读，脚本和文档里不抄：歌词在代码里叫 E1–E16，词按位置引用。

## 一条规则

**有一扇我们始终看不到的窗。它的光落进每个场景里，歌词是窗上的字，我们看不到字本身，只看到它对光做了什么。**

光块是按每个镜头的景深图投进去的，所以它会顺着台阶一级一级折下去，绕过咖啡杯，裹住肩膀。这是它和字幕、和起雾玻璃的区别：玻璃版的字在镜头前面，这一版的字落在场景里的东西上。

这条规则来自歌词的意思（被看见 = 被照到），也接上了片子本身：第一个镜头里她就坐在一扇带窗棂的窗前，最后一个镜头是同一扇窗的清晨。所以光块带着窗棂的影子、玻璃上的水珠和往下流的雨痕。

| | 光 | 字 |
|---|---|---|
| 前奏 | 还没人唱的时候，一块冷色的窗光已经落在她背上 | 只有片名小字 |
| 第一遍主歌 | 每句歌词一块窗光，落在门上、墙上、桌面、地面 | **影子**：跟着演唱从左到右写出来，唱完被窗上的雨水冲下去 |
| 预副歌 | 光块慢慢移动，颜色变暖 | 长音的那个词，影子越拉越长，像光变低时的影子 |
| 静默的 0.44 秒 | 窗光熄掉，整个画面暗下去 | 清唱的两个词是全片第一次以**光**的样子出现，落在她脸旁 |
| 第一次副歌 | 没有窗了，太阳出来 | 每个词都是一块金色的光，周围略暗；雨只有穿过字的时候才被照亮 |
| 间奏 | 回到灰色，窗光重新出现 | — |
| 第二遍主歌 | 同样的窗光 | 整句的影子先等在那里，唱到哪个词，哪个词就从影子变成**透光的彩色玻璃**，带一圈铅条一样的暗边：他看到了 |
| 第二次副歌 | 清唱那两个词的光向外扩开，铺满整个画面，正好是她抬头的那一拍 | 金色的光字 |
| 尾奏 | 清晨，真的阳光穿过真的窗 | 歌名那一句留在床上，一个词一个词亮起来；词曲署名 |

两遍歌词完全一样，差别放在字的状态上：第一遍是挡住光的影子，会被雨冲掉；第二遍是同一片影子被一个词一个词照亮。

## 几处单独的处理

- **共用一扇窗**：E4–E6 落在同一块地面光里，前一句被冲掉，后一句写在原处；E8 和 E9 的前三个词也共用落在她开衫上的那一块。
- **E7、E8（预副歌）**：第二个词是长音，它的影子在 3 秒多里拉长到 1.4–1.5 倍。
- **E9（歌名句）**：前三个词是影子；后两个词在伴奏停掉时变成光。第一遍它们一直亮到太阳出来，落在他的外套上；第二遍它们的光扩开成整个画面。
- **E13、E14**：说"留下"的那个词放大，落在两双脚旁边的湿地面上，跨三个镜头不灭；说"走开"的两个词向右滑走。
- **中文**：每句英文旁边一行小字（思源宋体），放在光块外面的暗处。
- **字体**：Georgia Bold。影子需要粗的字形才撑得住半影的模糊；斜度是投影给的，不是字体的斜体。

## 实现

- `scripts/light.py`：每句歌词是一个 `Group`，带一张"图案画布"（亮的窗格、窗棂、水珠、雨痕、字的遮罩），每帧用 `cv2.remap` 投到画面上。采样坐标 = 缩放和斜切 + 按景深的位移，位移以这块光中心的景深为基准，所以字留在摆好的位置，只在深度变化的地方折开。
  - `ground`、`wall`、`air` 三种投法：落在地面（压扁、斜切大）、落在墙面、没有窗的光字。
  - 光只落在近处的东西上（`far`），所以不会贴在天空上。
  - 冲掉、雨痕、光里的雨都挂在成片那条变速的钟上：预副歌变慢，静默时停住。
  - 亮度按画面局部明暗调整：暗处补一点底光，亮处少加，高光用软肩压住，白衬衫上不会一片死白。
- `scripts/render_light.py`：镜头、运镜、雨复用 `render.py`，光这一层插在镜头和胶片处理之间。`render.layer` 加了一个可选参数，把这一帧的景深图一起交出来。
- 每个镜头里光弯折的程度可以单独调（`kshot`）：有人站在光里的镜头调小，否则一个词会被人的轮廓切成几段。

## 这一版踩的坑

- 第一稿的光块又白又方，像贴了一张纸。改成亮度不均匀（一角更亮）、加窗棂和水珠、亮处少加光之后才像窗光。
- 景深位移太大时，站在光里的人会把一个词切成三四段。公交站那个镜头把位移降到十分之一才读得出来。
- 光落在很暗的近处物体上（深色外套）会变成一块灰板，因为补的底光不带物体本身的颜色。把底光调低后好一些，但暗场景里的光块仍然偏灰。
- 第二遍的整句影子提前出现时，上一句还没走，两块光叠在她身上。改了前一句的离场时间。
