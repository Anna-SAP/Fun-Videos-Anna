# Playbooks · 可复用的方法

作品页记录的是“这次怎么做的”，playbook 记录的是“下次怎么做”。每篇都说明它来自哪个作品，并附上能直接复用的命令或脚本。

| Playbook | 解决什么问题 | 来源作品 |
|---|---|---|
| [证据插入式剪辑](evidence-insert-editing.md) | 往解说视频里插原声：切点、音频门控、转场、响度、版式、事实核对；两次实践对比 | 贝叶斯 · AI 意识 |
| [音频互相关对齐](audio-sync-cross-correlation.md) | 两段视频怎么精确对齐（偏差小于 1 帧）；判断一段素材是从哪里剪出来的 | NEON · AI 意识 |
| [本地语音识别与时间码](local-asr-timestamps.md) | 不依赖平台字幕，拿到中文旁白 / 英文词级时间码；没有 ASR 时从硬字幕读时间轴 | AI 意识 · 贝叶斯 |
| [竖屏 9:16 构图](vertical-9x16-composition.md) | 横屏素材放进竖屏：完整画面 + 模糊填充、铺满裁切、相框嵌入 | NEON · 贝叶斯 · AI 意识 |
| [大文件与传输限制](large-files-and-transfer-limits.md) | 源片太大传不上来、成片太大写不回去、GitHub 100 MB 限制、写回文件不生效 | AI 意识 · 贝叶斯 · 归档 |
| [提示词模式](prompt-patterns.md) | 一份视频任务提示词该写什么，哪些没写会导致返工 | 全部 |

**新增 playbook 的标准：** 同一个方法在两个以上作品里用到，或者踩过一次值得记下来的坑。
