# 视频任务的提示词模式

来源：贝叶斯、NEON、AI 意识、NEON 双马尾的原始提示词（见各自的 `prompt.md`），以及执行中实际遇到的问题。

## 一直在用、效果好的骨架

```text
**任务目标：** 一句话说清最终产物
**输入素材：** 逐个列出，用文件名或关键词指认
**核心要求：** 编号列出，每条都可检验
**最终输出：** 格式、规格、文件名
```

这个骨架的好处：Claude 不需要澄清就能开工，执行时也能逐条对照验收。

## 容易漏写、导致返工或需要临时决定的项

| 漏写的项 | 后果 | 建议写法 |
|---|---|---|
| 素材在哪、多大 | 只给 YouTube 链接时云端拿不到，多了几轮交互 | “源视频已放在文件夹：xxx.mp4（1.2 GB）” |
| 成片时长上限 | AI 意识成片是主视频的 2.4 倍长；贝叶斯成片 2:08，事后才提出做 60 秒版 | “总长不超过 3 分钟 / 每段证据 ≤ 20 秒” |
| 能不能加片头、片尾、说明卡 | Claude 自己决定加上，事后再说明 | “允许 / 不要加片头；片尾加 / 不加免责说明” |
| 音轨用哪一路 | 需要 Claude 判断 | “用 B 的原声，结尾淡出” |
| 画面适配方式 | 交付了两版 | “完整画面 + 模糊填充” 或 “铺满裁切” |
| 字幕语言和样式 | 需要 Claude 判断 | “中文 + 英文原文双语，沿用主视频的字幕样式” |
| 事实核对 | 这次 Claude 主动做了，但不能每次都指望 | “列出主视频里与原话不符的说法” |
| 交付物清单 | 剪辑清单是 Claude 主动给的 | “附剪辑清单：插入点 + 原片时间码 + 字幕” |
| 用什么生成、预算多少（AI 生成类） | NEON 双马尾前半程都花在找通道上：Sora API 已停用、Weave 账号对不上、免费版不能用视频模型 | “用 Weave 上的 Kling 4.0 Video Edit，个人账号，预算 500 credits 以内，720p；每次运行前先报价” |
| 能不能直接改原片 | “视频 B 提供动作”字面上像是要重新生成；其实 A 已经和 B 同步，直接编辑 A 更好 | “可以直接在 A 上做视频编辑，同步以 B 的音轨为准” |
| 原片的字样、签名、取景要不要保留 | AI 编辑会抹掉文字、推镜也会偏，事后才补回 | “保留原片的 Logo 和作者签名；取景和原片一致，特写里发型要完整入画” |
