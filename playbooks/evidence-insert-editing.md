# 证据插入式剪辑（解说 + 原声实证）

**适用场景：** 已经有一条解说或科普视频（骨架），要在论证节点插入一手原声（访谈、发布会、论文作者讲话），做成“科普解析 + 实证实录”。

来源：[AI 意识访谈实证版](../projects/2026-10-21-02-ai-consciousness-evidence-cut/)、[贝叶斯理论解析 × 访谈实录](../projects/2026-10-19-01-bayes-theory-x-interview/)。两条都是“Gemini Notebook 生成的解说骨架 + 第三方访谈原声”。

## 流程

1. **划节点：** 识别骨架视频的旁白，按论点划出句群（AI 意识划出 13 个，贝叶斯划出 T1–T8），在每个句群末尾的停顿处标出候选切点。**骨架旁白不在句中切断。**
2. **选证据：** 一个节点配一段原声，标准按优先级排：
   - ① 直接对应骨架里的某句话（“快十倍”的出处）
   - ② 有具体细节（勺柄上有孔）
   - ③ 只有讲者本人在说话，没有主持人插话
3. **写 EDL：** 每段原声记成 `(video_in, video_out, audio_in, audio_out)`。
   - **音频门控：** 音频只卡讲者这句话的起止，前后的别的句子和插话都不进来。
   - **画面余量：** 画面比语音前后多留约 0.4 秒，给溶解转场用。
   - 一个证据可以由多个片段拼成（比如 45:02–45:15 + 45:17–45:23），用来去掉中间的废话。
4. **切点：** 切在旁白的自然停顿里，用 10 ms 粒度的能量扫描找最安静的点。每个分段首尾加 20–30 ms 的微淡入淡出，防止爆音。
5. **掩盖跳剪：** 同一段证据由多个片段组成时，交替片段做 0.9 倍 punch-in（轻微放大）。
6. **转场：** 段与段之间统一用 0.4 秒溶解（`xfade` + `acrossfade`）。
7. **响度：** 骨架旁白和访谈原声的响度差别通常很大。先逐段测量，再统一到 -16 LUFS（`ebur128` / `loudnorm`）。

## 画面层次（单个插入段）

```
┌──────────────────────────┐
│     [访谈实证 n/8]        │ ← 红色标签：第几段证据
│   这一段要证明的主张       │ ← 标题（一句话）
│ ┌──────────────────────┐ │
│ │  16:9 访谈画面（相框） │ │
│ └──────────────────────┘ │
│ ▍讲者 · 身份 / 节目 · 原片时间码 │ ← 署名条
│ ┌ 解析 ────────────────┐ │
│ │ 这段原话佐证了哪句话   │ │ ← 解析卡
│ └──────────────────────┘ │
│   English original (灰)   │
│  ┌ 中文字幕（沿用骨架样式）┐ │
└──────────────────────────┘
```

- **复刻风格：** 从骨架视频的帧里取色（纸张底色、字幕框颜色和阴影），用同一种字体（Noto Sans CJK SC），插入段才不会显得是另一个视频。
- **字幕断行：** 中文用 `|` 手动断行，不要单字成行，也不要让标点出现在行首。
- 可以先渲染一张静态预览图确认版式，再批量渲染。

## 可信度

- **逐句核对：** 字幕译文要对照原话。插入段渲染完后再做一次语音识别，和字幕比对。
- **找出骨架和原话的出入：** 骨架是 AI 生成的话，可能夸大或者编造。比如 AI 意识那条里，“苦修几十个小时冥想”在原声里找不到；贝叶斯那条的图上把先验标成了“先验偏见”。不改骨架的话，就在解析卡里引用原话，并告诉作者。
- **写明来源性质：** 讲者本人的讲述，不等于经过验证的结论。片尾要注明“为讲述者本人观点，尚未经独立验证”。
- **交付剪辑清单：** 成片位置、原片时间码、完整双语字幕都列出来，方便以后复核或重剪（见 AI 意识的 [edit-list.md](../projects/2026-10-21-02-ai-consciousness-evidence-cut/edit-list.md)、贝叶斯的 [edit-script.md](../projects/2026-10-19-01-bayes-theory-x-interview/edit-script.md)）。

## 两次实践对比

| | [贝叶斯](../projects/2026-10-19-01-bayes-theory-x-interview/)（10-19） | [AI 意识](../projects/2026-10-21-02-ai-consciousness-evidence-cut/)（10-21） |
|---|---|---|
| 证据来源 | YouTube 录屏，带英文硬字幕 | 访谈整集（2 h 47 min），没有字幕 |
| 时间轴 | 硬字幕像素差分 | 英文 ASR 词级时间码 |
| 证据画面 | 裁掉播放器边框；控件出现的 1.05–4.65 s 用 `drawbox` + `delogo` 遮掉 | 整段原片画面 |
| 转场 | 硬切，插入段开头 0.18 s 纸色淡入 | 全片 0.4 s 溶解 |
| 声音 | 固定增益 + 逐段 `alimiter`，-14.8 LUFS | 逐段测量后统一到 -16 LUFS |
| 纠错方式 | 叠「严谨注」卡（先验 ≠ 偏见） | 解析卡引用原话；片尾加“未经独立验证”说明 |
| 片头 / 片尾 | 去掉 Gemini Notebook 片尾，加公式片尾卡 | 加片头（检验逻辑）和片尾说明卡 |
| 成片 / 骨架时长 | 2:08 / 1:04 | 5:41 / 2:22 |

**共同的坑：** 两次都没给时长上限，成片都是骨架的 2 倍以上。下次在提示词里先定总时长和证据段数。

**音画长度锁定（贝叶斯）：** 逐段渲染时，视频用 `trim=end_frame=N`，音频用 `apad,atrim=end_sample=N*1600`（48 kHz ÷ 30 fps = 1600 个采样点 / 帧），拼接后就不会累积音画偏移。
